Cheat sheet

Git, the commands of a working week

What each does, in the order a change goes through them.

Start

git switch main
Go to the main branch
git pull --rebase
Bring it up to date, your commits replayed on top
git switch -c fix/total
Start a branch for one change

Look

git status
What changed and what is staged
git diff
The changes not yet staged
git diff --staged
The changes the next commit holds
git log --oneline -10
The last ten commits, one line each

Commit

git add -p
Stage a change hunk by hunk, saying yes or no to each
git commit
Commit what is staged; the editor opens for the message
git commit --amend --no-edit
Add what is staged to the last commit; only before it is pushed

Share

git push -u origin HEAD
Push the branch and track it
git push --force-with-lease
Push a rewritten branch unless someone else pushed to it

Undo

git restore file
Throw away a file's unstaged changes
git restore --staged file
Unstage it and keep the changes
git revert abc123
A new commit that undoes abc123

Never rewrite a branch others have pulled: revert instead.

Branch tidy-up

git branch -d fix/total
Delete a merged branch
git fetch --prune
Forget branches deleted on the server
# every local branch already merged into main
git branch --merged main
